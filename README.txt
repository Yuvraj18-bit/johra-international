JOHRA INTERNATIONAL WEBSITE

FILES
- index.html: website content and structure
- style.css: visual design, responsive layout, hover effects and animations
- script.js: mobile navigation, scroll-reveal animation and automatic footer year
- assets/yuvraj-saini.jpg: supplied proprietor portrait

PREVIEW LOCALLY
1. Open this folder in Visual Studio Code.
2. Install the Live Server extension if you do not already have it.
3. Right-click index.html and choose "Open with Live Server".

NOTES
- The website uses Google Fonts and Unsplash image URLs, so an internet connection is needed for those assets.
- The rug/interior images are illustrative stock references, not confirmed Johra International product or factory photos. Replace them with company-owned photos when available.
- The email links open the visitor's default email app; this static site does not currently submit a server-backed contact form.
- The proprietor portrait is included locally in assets/yuvraj-saini.jpg.
